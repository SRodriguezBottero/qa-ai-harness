# Contributing

Run locally with `npm install && npx playwright install chromium && npm run dev`, then open [http://127.0.0.1:4477](http://127.0.0.1:4477). To add an adapter, follow `docs/writing-an-adapter.md` — create a markdown file under `skills/*/references/`, register the type in `harness.config.json`, and keep vendor IDs out of the adapter markdown.
